# 云控 · 变频器租赁与监控 Demo

按照《变频器租赁与电机监控平台完整设计说明书及方案策划 V3.0》实现的三端联动演示。所有设备、用户、租金、运行数据与回执均为样例，不连接真实设备、不发起支付或短信发送。

## 启动

Windows 双击 **Start-Demo.cmd**，浏览器打开 http://127.0.0.1:4173。启动器优先使用已安装的 Node.js，也可使用当前电脑的 Codex 内置 Node。没有 Node 时会打开 dist/index.html，核心页面仍可体验；摄像头等浏览器能力可能受限。

也可在本目录运行：

    node server.cjs

建议使用新版 Edge 或 Chrome。数据保存在当前浏览器、当前网址的本地存储；换浏览器或网址不会共享数据。关闭服务可在任务管理器结束该服务对应的 Node 进程，或在前台启动时按 Ctrl+C。发布版与本地版是相互独立的演示环境。

## 三端页面

- 管理后台：工作概览、设备管理、合同登记与续租、客户档案、逐用户授权、三种统计表及收款明细、到期提醒、用户备份恢复、操作记录、短信接口预留。
- 监控中心：按原海南大屏设计实现，居中海南地图、左侧状态环图与区域运行条形图、右侧历史健康分析、底部导航和按需报警提示。区域页为左侧区域树及每页六台设备简卡，详情页为左侧资料、右侧参数与趋势。运行、通信和故障独立统计；监控只读。
- 手机小程序：设备列表、搜索筛选、扫码、设备控制与回执、租约与权限、历史趋势、消息、账号切换；管理员身份提供手机入库。

## 建议演示顺序

1. 在后台或管理员手机端“扫码入库”，填入新设备示例，核对后建档。
2. 登记合同：选已登记客户、租期与实收金额，核对第一所有人。合同不会自动授予控制权。
3. 切换小程序为签约客户，扫码添加这台设备。默认只能查看。
4. 后台“用户授权”选择设备和用户，授予启停或调频。回到小程序查看权限变化。
5. 新入库设备默认离线，在右上“演示场景”恢复在线，再启动或调频；回执需约 1 秒。
6. 模拟回执超时、设备故障或离线，观察实际状态与“结果待确认”的区别。
7. 推进演示时钟至到期，核对在线停机或离线待确认；登记续租后仍需手动启动。
8. 统计报表分别查看设备、月份、客户汇总，下钻到收款明细并导出 CSV。
9. 导出加密用户备份，再导入校验、核对范围与冲突、确认恢复。可将下载文件保存或复制到 U 盘；光盘需由电脑刻录工具完成刻录。
10. 需要重新演示时，在场景控制台“重置全部演示数据”。

初始时钟：2026-10-24 10:00，北京时间。该时钟由演示场景推进，不随电脑时钟自动前进。每次刷新保留业务数据，未确认的模拟指令不会被当成成功或自动重放。

## 重要业务边界

- 二维码包含厂商代号、变频器型号、4G 模块 ID，支持 + 或 | 分隔。摄像头扫码依赖浏览器 BarcodeDetector 支持和授权，不支持时可用示例、手动输入或扫码枪。
- 微信绑定仅模拟，演示客户没有经过真实微信验证。第一所有人以合同与管理员登记付款确定，扫码先后不改变归属。
- 权限按设备与用户分别设置；撤权后再次扫码不能恢复访问。
- 月租和收款使用整数分，按实际收款日统计；首次与续租分开留账。
- 本地用户主档与模拟云端执行镜像独立，离线变更待同步，不能提前提高实际权限或延长生效租期。
- 到期无默认宽限，在线设备模拟下发停机并等待回执。离线状态不等于停机成功；本 Demo 展示恢复在线后补停，真实离线强制到期依赖终端固件。
- 备份包含用户、设备关系、合同租期、权限和必要设备身份索引；排除运行数据、告警、控制记录、收款流水。加密使用浏览器 WebCrypto，密码不保存。
- 导入先校验解密与结构，逐项展示用户、合同与权限的当前值和备份值，并可先导出当前备份。核对差异与冲突后确认恢复；恢复不回滚云端演示流水或自动启动设备。
- 当前浏览器存储不等于正式本地数据库；真实本地服务、微信、4G 与云端接口须在下一阶段接入。
- 短信余额、充值、发送和扣费继续关闭，仅展示接口契约。

## 文件结构

- dist/index.html：入口；style.css：共享主题；app.js：三端外壳、扫码及弹窗。
- dist/demo.js：业务模型、演示数据、同步镜像、加密备份。
- dist/admin.js、mini.js、monitor.js：三个产品端；monitor-pages.js/css：区域、详情、报警页面；map-data.js：本地地图路径。
- tests：业务和浏览器验证脚本。
- server.cjs：仅监听本机的无依赖静态服务器。
- API.md：模块接口约定。LUCIDE-LICENSE：图标许可。

## V1.1 · 监控界面还原

- 全域总览沿用此前“海南省电机运行监控中心”设计：居中标题与青色折线、海南地图、两侧图表、底部导航。顶部展示当前演示设备实际统计，不套用设计图中的示例总数。
- 地图市县标记可逐级进入区域地图，再进入设备列表；区域统计不会随关键词改变；支持按所属人搜索、六台一页和返回保留筛选。
- 区域页可手动开启每 10 秒翻页轮播；人工筛选、翻页和查看详情会暂停轮播。
- 离线详情展示最后有效读数并标注“历史值”，曲线在最后上报时间处停止，后方显示缺测区间。
- 右上角或底部“工作台”可以切换管理后台、手机端、演示场景和指南。全屏按钮由浏览器决定是否允许。
- 地图资源已内置，不需要在线请求；来源见 MAP-SOURCE.md。历史运行及健康曲线标为合成示例。

本轮验证：监控界面 10 项、共享流程 12 项浏览器检查通过；桌面主屏 1920×1080 与 1440×900 完整显示，390px 手机宽度可纵向浏览。


## V1.2 · 地图逐级展开

- 在全域总览中点击市县边界或城市标记，进入该市县的放大地图。
- 海口、三亚可继续点击下辖区进入区级地图；其他已载入的市县展示自身区域边界，没有本地下级边界时明确显示当前层级终点。
- 地图页提供面包屑、返回上一级、放大/缩小/复位以及设备列表入口。刷新保留当前地图层级，从设备详情返回时回到原地图。
- 地图中的区域名称是行政区域聚合，不是具体设备坐标。现有设备没有登记区县时，计入市县总数并显示“区县待登记”，不会按安装地址文字猜测归属。
- 只有明确且属于当前市县的 districtCode 才计入某区的设备统计；从区级地图进入设备列表时保留该区范围。
- map-levels.js 内置本地下钻几何，monitor-map.js/css 提供地图页。浏览器打开本地 HTML 后不依赖外部地图服务。

本轮验证：地图下钻 13 项、监控界面 10 项、共享流程 12 项检查通过。直接 file:// 打开、断网下钻、刷新恢复和 390/1440/1920 屏宽均已验证。
