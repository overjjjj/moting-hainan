# 区域设备 UI 设计稿

> 历史静态设计参考。当前 Demo 已实现对应页面，并新增地图逐级展开；最新行为见 ../../demo/README.md。图中的设备数量、温度和转速等示例不等于已接入的测点。

沿用已讨论的海南监控大屏深蓝底色、青色标题线和数据强调色。使用内置 ImageGen 生成，当前为静态设计稿，未实现交互或接口。设备、人员、乡镇、读数和历史均为演示数据。

## 页面

1. [区域设备总览](01-region-overview.png)：区域树、当前区域统计、组合筛选、每页六台简要设备卡片、分页和全域报警提示条。
2. [单台设备详情](02-device-detail.png)：设备资料、实时参数、历史趋势、故障确认与恢复状态、最近事件。
3. [搜索无结果](03-search-empty.png)：保留区域总数，明确筛选结果为零，提供清除筛选入口。
4. [离线设备详情](04-offline-detail.png)：最后有效读数明确标为历史值，曲线在断点停止，不把缺失值画为零。

## 交互约定

- 全域总览点击市县进入区域设备，并携带区域条件。
- 区域、状态、关键词共同筛选；切换条件回到第一页。人工操作暂停轮播。
- 点击卡片进入详情；返回时保留区域、关键词、状态和页码。
- 当前区域统计不因关键词而变；筛选结果单独显示。
- 卡片保持编号顺序；报警不得导致卡片重排。
- 报警提示只在有未确认记录时出现。确认不代表恢复；现存故障仍在卡片与统计中体现。
- 离线、运行状态、故障、数据新鲜度在正式模型中独立处理，不能把离线推断成停止。
- 本套图包含历史趋势的视觉预留；保存期限与接口实现仍待逐项规划。
